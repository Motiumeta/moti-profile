# Moti Profile

Welcome to my personal portfolio website repository! 

This project is a multi-page personal website built entirely with **pure HTML5**. It serves as a digital resume and a showcase of my learning journey, technical skills, and projects. 

## 🌐 Live Preview
*(You can add your GitHub Pages link here once you deploy it, e.g., `https://yourusername.github.io/moti-profile/`)*

## 📄 Pages Included
The website consists of six interconnected pages linked by a consistent navigation menu:
1. **Home (`index.html`)** - A brief introduction and personal motto.
2. **About Me (`about.html`)** - My background, values, and future ambitions.
3. **Skills & Education (`skills.html`)** - My educational background, technical skills (Flutter, C++, Java, etc.), and current learning goals.
4. **Projects & Achievements (`projects.html`)** - A showcase of my Gym Management System, Bus Seat Booking System, and Exam Seat Allocation System.
5. **Media & Interests (`media.html`)** - Topics I enjoy, along with embedded audio and video elements.
6. **Contact (`contact.html`)** - A fully functional HTML form with validation, alongside my contact information.

## 🛠️ Technologies Used
* **HTML5:** Semantic tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`)
* **Form Elements:** Inputs, labels, fieldsets, and validation attributes.
* **Multimedia:** Native HTML5 `<audio>`, `<video>`, and `<iframe>` for YouTube.
* **Tables:** Used for structuring education and skill data.

*(Note: As per the lab exercise requirements, no CSS or JavaScript has been used in this version. Styling will be added in future iterations.)*
